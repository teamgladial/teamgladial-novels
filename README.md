# Gladial Novels

A static Astro home for novels and fiction published under the Gladial umbrella. Add book entries and reading links as stories are ready to publish.

## Local development

```sh
npm install
npm run dev
```

## Cloudflare Pages

- Build command: `npm run build`
- Build output directory: `dist`
- Node.js: `>=22.12.0`

This is a static Astro site; no Cloudflare adapter or server runtime is required.
